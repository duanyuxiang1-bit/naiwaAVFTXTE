# naiwaAVFTXTE

`naiwaAVFTXTE` 是抖音 W0Wsai 定制发布的 Windows 10/11 x64 奶蛙低占用 2D 键鼠联动桌宠，当前版本为 **0.6.5-preview**。

它提供小奶蛙与十二生肖角色、键鼠动作联动、透明置顶桌宠、托盘设置，以及供 OBS 使用的本机透明浏览器来源。程序不拦截或修改输入，不保存按键文本或按键历史；直播画面服务仅绑定 `127.0.0.1`，不向互联网发送输入或画面。

## 使用说明

- 默认桌宠位于主屏右下角，置顶、锁定且点击穿透。
- 系统托盘中的奶蛙图标可用于移动、隐藏、暂停、设置或退出。
- 默认显示/隐藏快捷键为 `Ctrl+Alt+H`。
- “更换角色”可选择小奶蛙与十二生肖。
- OBS 直播输出方式、构建说明和已验证范围请见 Release 完整包内的 `README.md` 与 `VALIDATION.md`。
